# АКиОС - Лабораторная работа №1

Скрипты для архивации логов.

## Файлы

- `script1.sh` - архивирует старые логи при переполнении папки.
- `script2.sh` - тесты для проверки работы `script1.sh`.

## Требования

Для работы тестового скрипта (`script2.sh`) и монтирования виртуального диска необходим пакет `fuse2fs` (позволяет работать без прав root).

Установка в Ubuntu/Debian:
```bash
sudo apt install fuse2fs
```

## Запуск

### Запуск основного скрипта
```bash
./script1.sh <путь> [порог]
```

- `<путь>` - путь к папке с логами (обязательный аргумент).
- `[порог]` - процент заполнения (от 0 до 100, по умолчанию 70).

**Примеры:**
```bash
# Запуск с порогом по умолчанию (70%)
./script1.sh /log

# Запуск с явно указанным порогом (85%)
./script1.sh /log 85
```

### Запуск тестов
Скрипт `script2.sh` полностью автоматизирует процесс: сам создаёт виртуальный диск через `fuse2fs`, наполняет его файлами, проверяет работу `script1.sh` и чистит за собой.

```bash
./script2.sh
```
